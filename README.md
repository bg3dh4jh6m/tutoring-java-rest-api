# Tutoring Java REST API

A Spring Boot and JDBC warehouse exercise for tutoring REST endpoints, repositories and integration tests.

## Learning goals

- REST controller design
- JDBC repositories and transactions
- integration testing against a local database

## Run

Configure a disposable local MySQL database, then run `./mvnw test` and `./mvnw spring-boot:run`.

## Publication note

All names and data are synthetic. This repository has a new tutoring-only history and contains no production configuration.
